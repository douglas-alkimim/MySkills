# Presentation Module

Start with audience, speaking context, decision, duration, and takeaway. Build a narrative arc before slide decoration.

Define slide purpose, evidence, visual hierarchy, source notes, speaker notes, and ownership of reusable layouts. Prefer one message per slide and visuals that encode the relationship instead of ornamental graphics.

Acceptance includes factual review, source verification, consistency, accessibility, slide-level overflow inspection, image quality, contrast, typography, transitions where relevant, and full-deck rendering in the target format.
