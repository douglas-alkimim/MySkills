# PDF Module

Determine whether the PDF is authoritative output, editable source, archival artifact, form, or review copy. Identify page size, fonts, image quality, links, bookmarks, metadata, accessibility, and security requirements.

For creation, retain the true source artifact and reproducible generation path. For edits, distinguish content reconstruction from annotation, form filling, rearrangement, or metadata changes.

Validate file structure, page count, text extraction where relevant, embedded fonts, links/forms, and every rendered page. Never rely only on successful serialization.
