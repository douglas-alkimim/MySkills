# Spreadsheet Module

Define workbook grain, source data, field meanings, calculation ownership, units, dates, null policy, and refresh behavior before formulas or charts.

Plan:

- raw, transformed, calculation, and presentation layers;
- stable tables and named ranges;
- formulas, error handling, reconciliation, and controls;
- input validation and protected cells;
- pivots, charts, filters, and print/export layout;
- recalculation and compatibility requirements.

Acceptance includes formula inspection, recalculation, boundary cases, source-to-output reconciliation, chart truthfulness, formatting, and rendered or print-area review. Do not hard-code a result that should remain a formula.
