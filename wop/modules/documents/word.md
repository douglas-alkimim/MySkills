# Word and DOCX Module

Plan styles before local formatting. Define page setup, heading hierarchy, body style, lists, captions, cross-references, headers/footers, tables, figures, citations, and accessibility metadata.

Preserve editability unless the user requests flattened output. For tracked changes or comments, define author identity, review policy, accepted/rejected scope, and clean final copy.

Verification must render the DOCX and inspect every page for overflow, orphan headings, broken tables, clipped images, incorrect numbering, unresolved fields, and inconsistent styles. Re-open the final file to confirm it remains valid.
