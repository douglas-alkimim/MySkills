# Final Acceptance

Mandatory at every planning level. Apply only the domain-specific rows that are relevant, but never infer acceptance from planned work or reduce the evidence threshold because a plan is Compact.

- [ ] All planned waves passed their completion gates in order.
- [ ] Every item has actual acceptance evidence.
- [ ] Integration and end-to-end verification passed.
- [ ] Every requirement is satisfied or explicitly rejected with consequence.
- [ ] No unresolved blocker is hidden.
- [ ] Deliverables exist at the stated locations and formats.
- [ ] Security, performance, editorial, or domain-specific gates passed where applicable.
- [ ] Deviations were reviewed and reflected in a plan revision when material.
- [ ] Execution status reflects actual completion and references produced execution evidence with an identifiable actor.
- [ ] Acceptance status reflects an actual evaluation and references produced acceptance evidence, including human approval when required.
- [ ] Final report identifies evidence, limitations, residual risks, and handoff.
