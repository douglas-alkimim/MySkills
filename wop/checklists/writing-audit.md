# Writing Audit

## Essential — every plan

- [ ] Objectives, boundaries, outputs, and completion criteria are actionable.
- [ ] Terms and identifiers are consistent.
- [ ] No critical instruction relies on chat history or “as discussed.”
- [ ] No generic filler, empty boilerplate, or repeated explanation remains.
- [ ] Every sentence changes likely behavior or preserves necessary context.
- [ ] Completion criteria are observable.
- [ ] Standalone prompts contain their execution-critical excerpts.

## Complete — Standard and Extensive

- [ ] Inputs, ownership, restrictions, evidence, and handoff are explicit wherever relevant.
- [ ] Shared contracts have one authoritative definition.
- [ ] Global protocol rules are universal; item assignments live only in wave instructions.
- [ ] No prompt repeats prerequisites, scope, or completion material in multiple primary blocks.
- [ ] Progressive disclosure routes only relevant specialist detail.
- [ ] Facts, decisions, assumptions, unknowns, requirements, and evidence remain distinct.

Compact plans need not produce a long writing report when all Essential checks pass. Report specific evidence for any failure.
